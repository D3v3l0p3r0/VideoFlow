# Third-party components

VideoFlow uses the following separately licensed components. This file is an inventory, not a replacement for their license notices.

- Python / Tk: runtime and native window toolkit.
- yt-dlp: extraction and downloading; includes its own platform extractors and license notices.
- CustomTkinter: interface widgets.
- Pillow: images and icon generation.
- certifi and truststore: certificate handling.
- PyInstaller and its hooks: executable packaging.
- FFmpeg: external media processor, not bundled with the executable.

Dependency names and exact versions of the supplied build are recorded in `requirements-tested.txt`. Inspect the upstream license notices for the versions you distribute. VideoFlow's own project license has not been selected in this kit.
