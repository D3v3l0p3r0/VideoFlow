# Changelog

## 1.4.1

- Ctrl+V and Shift+Insert paste URLs from any app section.
- Ctrl+L focuses the URL field in English and Russian keyboard layouts.
- Native text paste is preserved in the destination folder field.
- Paste is handled before Tk's built-in handlers to prevent duplicated URLs.

## 1.4.0

- RU/EN localization with a bottom-left language button and persistent preference.
- Compact, always-visible folder, format, quality and playlist settings.
- Removed decorative and duplicate labels.
- One logo source for the sidebar, window, taskbar and EXE resources.
- Explicit Windows application identity and ICO configuration.
- Clean publication kit, bilingual documentation and Windows build workflow.

## 1.3.0

- Graphite/light interface, redesigned queue and history, inline URL analysis.

## 1.2.0

- Automatic URL analysis and public Mail.ru Music tracks.

## 1.1.0

- Dzen and Yandex Video preview compatibility.
